# Pilot study (step 9, weeks 8–10)

**Design:** 6–10 intended users, fictional scenarios (`data/pilot/scenarios.md`),
within-subjects: each participant uses the baseline and the new tool; half start with
each version (counterbalanced) to reduce practice effects. Reviewer assesses content
separately.

Enable anonymous query logging during sessions: `ORTHOINFO_LOG_QUERIES=1 orthoinfo serve`.
