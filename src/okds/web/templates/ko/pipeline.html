Each article is a Markdown file in data/pipeline/articles/<topic>/. Skipped ones keep only the reason.

Add a document your team has the right to use: a partner report, a guideline, an article, a protocol. It goes through automatic checks into the article inbox, Job 2 drafts a KO from it (with other articles on the topic), and a person reviews the draft. No patient information in documents; for structured records use Data Skeleton.

Automatic checks: the topic exists, it has a title and 500+ characters of text, the reuse rules allow it (not "restricted"), and the same text wasn't added before.

Run it every day on this computer

Windows (Task Scheduler, in a terminal):

schtasks /Create /SC DAILY /ST 07:00 /TN "KO pipeline" /TR "cmd /c cd /d <project folder> && .venv\Scripts\okds.exe pipeline run >> data\pipeline\task.log 2>&1"

macOS / Linux (crontab):

0 7 * * *  cd <project folder> && .venv/bin/okds pipeline run >> data/pipeline/cron.log 2>&1

Without an AI key use okds pipeline run --template. Later in the cloud: EventBridge Scheduler runs each job as an AWS Lambda function; the inbox, queue and library move to S3, and the AI key to Secrets Manager.
